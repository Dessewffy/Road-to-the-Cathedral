# Road to the Cathedral

**Status: In Development**

## Project Purpose

Road to the Cathedral is a personal game development project created for **learning purposes and portfolio development**. It serves as a practical way to develop and demonstrate my skills in Unity and C# game programming.

## Third-Party Assets and Licensing

This repository does not include certain third-party assets used in the original Unity project, such as asset packs, models, textures, animations, and visual effects.

These assets were excluded to respect the original creators' intellectual property rights and the licensing terms under which the assets were obtained. Some asset licenses allow assets to be used in games but do not permit their standalone redistribution in a public repository.

The `.gitignore` file is configured to exclude selected directories containing third-party assets while keeping the project's own source code and development files under version control.

**Please note:** The project may not work or look exactly as intended when cloned, as some scenes and prefabs may reference assets that are not included in this repository.
